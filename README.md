## 📱 About the Project

**گنج کیش** is an innovative mobile and web application that transforms tourism into an exciting adventure game. Users explore Kish Island through various missions, collect treasures, unlock achievements, and compete on leaderboards.

### 🎮 Core Features

- **👤 User Authentication** - Secure login with Google OAuth & Email
- **🗺️ Interactive Map** - Explore 9 iconic locations on Kish Island
- **🎯 Mission System** - Complete daily/weekly challenges and quests
- **🏆 Achievements & Rewards** - Unlock badges and collect treasure
- **💰 In-Game Economy** - Earn coins, buy items, upgrade skills
- **👥 Social Leaderboard** - Compete with other players globally
- **🎮 Game Modes** - Puzzle games, photo challenges, trivia
- **📊 Profile & Statistics** - Track your journey and progress
- **🔔 Real-Time Notifications** - Get updates on missions and achievements
- **🛒 Shop System** - Purchase items and power-ups

## 🛠️ Tech Stack

### Frontend
- **React 18** - UI library
- **TypeScript** - Type safety
- **Vite** - Next-gen build tool
- **Tailwind CSS** - Utility-first CSS
- **Redux Toolkit** - State management
- **Framer Motion** - Advanced animations
- **Leaflet.js** - Interactive maps
- **Socket.io** - Real-time communication

### Backend
- **Node.js + Express** - Server runtime
- **MongoDB** - NoSQL database
- **JWT** - Authentication tokens
- **Socket.io** - WebSocket support
- **Redis** - Caching & sessions

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn
- MongoDB

### Installation

1. Clone the repository
2. Install dependencies: `npm install`
3. Setup .env file
4. Start dev server: `npm run dev`
